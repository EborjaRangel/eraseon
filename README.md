# EraseOn

Registro de bardas con brocha mágica: consecutivo único, fecha y hora, cinco fotos de antes, cinco de después, globo en el mapa y área en metros cuadrados.

## Arranque

```bash
npm install
npx prisma db push
npm run dev
```

Abre http://localhost:3000

La base local es SQLite en `prisma/dev.db`.
